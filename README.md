# Real-Time Ride Analytics & Surge Pricing Pipeline

## Project Overview
This project simulates a real-world Uber-like ride analytics system using Python, Pandas, SQL, and data engineering concepts.

## Features
- Real-time ride data simulation
- Data cleaning pipeline
- Missing value handling
- Dynamic surge pricing logic
- SQL analytics engine
- GitHub version control

## Tech Stack
- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Git & GitHub
